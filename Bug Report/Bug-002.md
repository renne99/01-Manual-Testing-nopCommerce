# BUG-002 - User account is activated without email verification

**Title:** User account is activated without email verification<br>
**Related Scenario:** TS_01<br>
**Environment:** Chrome / Windows 11 / demo.nopcommerce.com<br>
**Steps to Reproduce:**

1. Open https://demo.nopcommerce.com/
2. Register using any valid email address
3. Complete and submit the registration form

**Expected Result:** The user should need to verify their email before the account is activated.<br>
**Actual Result:** The account is activated immediately, with no email verification step.<br>
**Severity:** Medium<br>
**Priority:** Medium<br>
**Status:** Open<br>
