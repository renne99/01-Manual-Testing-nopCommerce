# BUG-001 - Weak password is accepted during user registration

**Title:** Weak password is accepted during user registration<br>
**Related Scenario:** TS_01<br>
**Environment:** Chrome / Windows 11 / demo.nopcommerce.com<br>

**Steps to Reproduce:**

1. Open https://demo.nopcommerce.com/
2. Navigate to the Register page
3. Enter valid details in all other fields
4. Enter a weak password: "123456"
5. Submit the registration form

**Expected Result:** The system should reject the weak password and display password strength requirements.<br>
**Actual Result:** The registration completed successfully with the weak password.<br>

**Priority:** High<br>
