# BUG-003 - System allows duplicate products to be added to the wishlist

**Title:** System allows duplicate products to be added to the wishlist<br>
**Related Scenario:** TS_07<br>
**Environment:** Chrome / Windows 11 / demo.nopcommerce.com<br>

**Steps to Reproduce:**

1. Navigate to any product page
2. Click "Add to wishlist"
3. Click "Add to wishlist" again for the same product

**Expected Result:** The system should prevent duplicates, or notify the user the item is already on the wishlist.<br>
**Actual Result:** The same product is added multiple times with no warning.<br>
**Severity:** Medium<br>
**Priority:** Medium<br>
**Status:** Open<br>
